# GoodMood — LifeOS Transformation System

A mobile-first personal operating system designed to engineer a sustainable transformation from **95.0 kg to 73.0 kg lean shredded avatar**, solving deep-seated challenges in physical health, career focus, and daily discipline.

## 🌟 Core Architecture (The 4 Pillars)

### 1. 🌿 Health & Mind
* **💧 4-Litre Water Engine:** Interactive animated Water Can liquid level tracking with `+` and `-` 250ml quick-tap buttons.
* **🔔 Smart Water Reminder:** Configurable intervals (default 30 mins) with native Web Push notifications and audio voice chime.
* **🧘‍♂️ 5-Min Zen Meditation:** 4s Inhale, 4s Hold, 6s Exhale stress reset timer.
* **🛡️ 4 PM Snack Shield:** Deep-fried and sugar tea counter with `+`/`-` controls.
* **🥗 Daily Diet Meal Slots:** Dedicated Target vs Eaten log inputs for Breakfast, Lunch, 4 PM Snack, and Dinner.

### 2. ⚔️ Strength
* **🚶‍♂️ COC Troop March (Live GPS Walking Tracker):** Real-time GPS distance calculation (Haversine formula), live speed (`km/h`), and loot calories burned counter.
* **🔥 Hanging Belly Vacuum (TVA Core):** 30-second transverse abdominis vacuum hold timer to tighten saggy abdominal wall.
* **🏋️ Progressive Overload:** Pushups (Wall, Incline, Knee) and Dead Hang pull-up conditioning tracker.

### 3. 🪙 Wealth
* **🎯 Career Deep Focus:** 25-minute Pomodoro lockdown to combat work focus fluctuation and procrastination.
* **💡 Sudden Idea Vault:** 1-second rapid brain dump for business, software, and creative ideas.

### 4. 🚀 Growth
* **📖 LexiCraft PWA Integration:** Instant one-click launch to English vocabulary and audio learning app.
* **🗣️ 3-Minute Audio Shadowing:** In-browser Speech Synthesis phrase player for daily conversational speaking confidence.
* **🤝 Commitments & Wish Vault:** Dedicated reminder list for social promises and birthday wishes.

## 🚀 Getting Started

1. Clone repository:
```bash
git clone https://github.com/Manikandan12155/goodmood.git
cd goodmood
```

2. Run persistent local server:
```bash
python app_server.py
```

3. Open in Mobile Browser (same Wi-Fi):
```
http://<YOUR-LOCAL-IP>:3000
```
Add to Home Screen for native app experience!
